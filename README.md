# AsetPix

Сайт студии персональной анимации: https://asetpix.kz/.

Статический HTML, CSS и JavaScript. Сборка и сервер приложения не нужны. Node.js используется только для форматирования и проверки JavaScript.

## Структура

```text
index.html               Главная страница, русский текст и окно согласия
privacy.html             Политика конфиденциальности (прямая публичная ссылка)
assets/                  Изображения и иллюстрации
styles/
  main.css               Оформление сайта и адаптивные размеры
  privacy.css            Окно согласия и страница политики
scripts/
  config.js              WhatsApp, тарифы, ID пикселя, версия согласия
  translations.js        Казахский и английский переводы
  app.js                 Языки, калькулятор, меню, сравнение фото, анимации
  consent.js             Согласие и события Meta Pixel
```

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. При первом посещении появится окно согласия. Политика доступна без согласия по `/privacy.html`.

## Проверка и форматирование

```sh
npm ci
npm run format
npm run format:check
npm run check
```

Prettier закреплён в `package-lock.json`. Настройки отступов находятся в `.editorconfig` и `.prettierrc.json`. Для VS Code можно использовать расширение Prettier и форматирование при сохранении.

## Частые изменения

- **Тексты:** русский — в `index.html`, атрибуты `data-i` связывают их с ключами в `scripts/translations.js`. Сохраняйте одинаковые ключи во всех языках.
- **WhatsApp:** `scripts/config.js` → `whatsapp`. Также обновите исходные `href="https://wa.me/..."` в `index.html` и телефон в `privacy.html`. Скрипт добавляет в ссылки сообщение на выбранном языке.
- **Цены:** `scripts/config.js` → `rates`, стоимость одной минуты по порядку База / Стандарт / Премиум. Видимые цены кнопок тарифов находятся в `index.html`; изменяйте их вместе с настройкой.
- **Изображения:** в `assets/`; пути в HTML начинаются с `assets/`, в CSS — с `../assets/`.
- **Meta Pixel:** ID в `scripts/config.js`. Загрузка и события находятся только в `scripts/consent.js`.
- **Политика:** `privacy.html`. При существенном изменении условий обновите дату политики и `consentVersion` в `scripts/config.js`, чтобы запросить выбор повторно.

Скрипты подключаются с `defer` в порядке: `config.js`, `translations.js`, `app.js`, `consent.js`. Это обычные скрипты без сборки; `SITE_CONFIG` и `translations` доступны следующим скриптам. Не меняйте порядок без изменения зависимостей.

## Согласие и аналитика

До основного согласия содержимое сайта скрыто и имеет атрибут `inert`. Рекламная аналитика — отдельный необязательный выбор. Посетитель может пользоваться сайтом и WhatsApp без неё.

- Выбор сохраняется в `localStorage` под ключом `asetpix-privacy-consent` с версией и временем. Это локальная настройка браузера, а не серверный журнал согласий.
- Настройки можно повторно открыть из подвала. Отзыв аналитики прекращает отправку новых событий. Уже отправленные данные автоматически не удаляются.
- `PageView` отправляется один раз за загрузку страницы, после согласия на аналитику.
- `Contact` отправляется по клику на ссылку `wa.me` или `api.whatsapp.com`. Событие означает клик, не отправку сообщения и не покупку.
- Содержимое WhatsApp-сообщения в параметры события не добавляется. Сам Meta Pixel может передавать технические данные браузера.
- Блокировщики и отказ от аналитики могут препятствовать отправке событий. Фактическое получение проверяйте в Meta Events Manager → Test Events.

При тестировании используйте отдельный профиль браузера. Не генерируйте массовые тестовые события в рабочем пикселе.

## Публикация

GitHub: https://github.com/KairatZhanygulov/Asetpix

Vercel подключён к ветке `main`: push запускает автоматическое обновление. Настройки проекта: preset **Other**, корень репозитория, output directory `.`, build command отсутствует. Статические страницы публикуются без сборки; `node_modules` не хранится в Git.

Перед публикацией:

1. Выполните проверки форматирования и синтаксиса.
2. Проверьте мобильный экран, смену RU/KK/EN, тарифы и длительность калькулятора.
3. Проверьте первый вход, отказ от аналитики, согласие и повторное открытие настроек.
4. Проверьте ссылки WhatsApp и прямую ссылку `/privacy.html`.
5. После push дождитесь успешного deployment в Vercel.

При изменении CSS/JS увеличивайте параметр `?v=` соответствующего подключения в HTML для обновления браузерного кеша.

## Текущие ограничения

Русский текст служит исходным для переключения языка. Политика и окно согласия пока только на русском. Формы, база заявок и backend отсутствуют; обращения поступают напрямую в WhatsApp.
